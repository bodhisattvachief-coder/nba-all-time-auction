# 全时代NBA巨星竞价战

直接双击 `index.html` 即可游玩，不需要安装依赖或启动服务器。

## 规则

开始界面提供“规则讲解”按钮，可在游戏内查看完整规则。

- 球员池共 200 人，包含 NBA 75 周年队的全部 76 位入选者、现役强力球员和 2000 年以后活跃的球星。
- 每局随机抽取 12 人，至少 8 人是现役球员，并固定混入 3 名现实评价相对较弱的“雷”球员。
- 现役模式只使用现役球员，All-Time 模式使用完整 200 人历史球员池。
- 盲盒模式会在竞价中隐藏全部身份，只公开球队主题颜色，完成全部选择后统一揭晓。
- 所有球员统一从 1 美元起拍，加价幅度每次 1 美元。
- 你与 AI 各有 20 美元，通过加价或放弃竞拍球员。
- 选人阶段不限制位置，每队可以自由获得任何位置的 6 名球员。
- 拍卖结束后先点击球员卡，再点击目标位置完成排阵；位置冲突会自动交换。
- 球员离开本色位置会扣分：相邻位置扣分最少，跨位置越多扣分越高。
- AI 会评估球星上限、阵容差距、位置稀缺度和你的建队进度，并动态调整竞价上限。
- 拍卖结束后，系统会从核心天赋、进攻、防守、组织、投射、篮板和替补深度等维度评分，并预测系列赛结果。

球员身份和历史时期会在 2K 风格翻卡的正面标明。能力评分是游戏化数值，不代表官方球员排名。

200 张离线缩略头像取自对应球员的 Wikipedia 页面图片或 NBA 官方头像服务，图片权利归原作者或权利方所有，仅用于本地非商业演示。
